Chat Compiler puts a code editor on top of your AI chat, so you stop switching between your compiler and ChatGPT.

When an AI is helping you with code, you end up running it somewhere else, copying the output, and pasting it back. Chat Compiler adds a floating, Cursor-style editor to ChatGPT, Claude, Gemini, DeepSeek, Perplexity and Grok, so you can write and run code without leaving the chat.

Features
• Run Python and JavaScript right in your browser. Python works offline with no setup.
• Give your program input the way you would in a terminal.
• Send your code, input and output to the chat in one click, with an optional message like "why does this fail?"
• Pull the AI's last code block into the editor to run it.
• Stop infinite loops without freezing the page.
• Move it, resize it, and hide it with Alt+Shift+K. Your code and layout are saved.

Privacy: Your code stays on your computer. Nothing is collected or sent anywhere unless you click Send.
